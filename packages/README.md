# SDK tarball

Copy the approved SDK package tarball here before running `npm install`:

```bash
mkdir -p packages
cp ~/Documents/open-feature-flag-sdk-source/src/sdk/lendistry-openfeature-0.1.4.tgz packages/
```

The demo expects `packages/lendistry-openfeature-0.1.4.tgz`. This folder intentionally does not contain the SDK source code; the SDK is maintained in its own repository.
